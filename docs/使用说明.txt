Rivulet 若 v0.10.1(Windows 64 位,一个 exe 全功能)

【怎么打开】
1. 把 Rivulet若-v0.10.1-win64.exe 放到桌面或 D 盘都行,
   不要放在系统盘的程序目录里(那里没有写权限)。
2. 双击运行。第一次启动要等 20~40 秒 —— 它要把内置的运行环境
   (Python + QQ 协议端,共约 350 MB)解压到 exe 旁边的目录里。
   之后启动只要几秒。
3. 如果弹出「Windows 已保护你的电脑」:点「更多信息」,再点「仍要运行」。
   这个程序没有做数字签名,提示是正常的。
4. 第一次用,在登录页点「注册」建一个账号,然后登录。
   账号只存在这台电脑上,不上传任何服务器。

Windows 11 自带运行环境。Windows 10 打不开的话,先装微软的
Edge WebView2 Runtime(搜索 "WebView2 Runtime 下载",装完重开)。

【这个包已经内置了什么】
不用另装 Python、不用另装 Node、不用另装 QQ 协议端:
- runtime\          自带的 Python,含全部依赖(含生成二维码的库)
- fatfish\NapCat\   自带的 QQ 协议端(无头版,不弹窗、不要管理员)
- fatfish\bili\     B站模块(扫码登录、投稿、稿件管理、每日推荐)
- core\             本机账号服务
- services\         QQ / B站 / 人格 / 心情 / 一键部署 等功能服务

【第一次用会看到什么】
登录进去后会先落到「一键部署」,不是首页 —— 这是给新用户准备的引导。
三步跟着走完(或者点右上角「跳过引导」),之后每次就直接进首页了。

【要自己配的】
工作区的模型:要让模型回答,在设置里填自己的 API Key(比如 DeepSeek)。
记忆库的语义检索:默认关闭,要另配一个向量服务;不配也能用关键词搜索。
B站:在 B站 页面点「扫码登录」,用手机 B站 扫一下就行。
QQ:在 QQ 页面点「启动协议端」,等二维码出来,用手机 QQ 扫一下。
    扫码后协议端会自动登录,不用管它。

【数据放在哪】
你的数据在 data\、core\data\、services\data\、fatfish\data\ 几个目录里,
第一次用到时自动建。
搬家时整个文件夹一起搬。登录状态和各种 Key 用当前 Windows 账号加密,
换电脑或换 Windows 账号后要重新登录、重新填。
这些目录里有你的聊天、记忆和登录状态,不要发给别人;
想分享这个程序,发最开始那个 exe(它里面没有任何人的数据)。

【账号与权限】
自助注册只能建普通用户,注册不出管理员。
管理员账号只能在本机登录:换一台电脑、或者从外部网络访问,
即使密码对了也会被拒绝(提示「管理员账号只能在本机登录」)。
账号服务只监听 127.0.0.1,外部本来就访问不到。

【打不开或登录不上】
- 第一次启动慢是正常的(在解压),看 exe 旁边有没有多出 runtime\ 和 fatfish\。
- 提示连不上账号服务:等十几秒再试;还不行看 core\core.log。
- 8088 端口被别的程序占了也会连不上,换掉那个程序再开。
