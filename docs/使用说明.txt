Rivulet 若｜Windows 快速使用

1. 把单文件 exe 放进自己能写入的文件夹，双击打开。第一次可能需要几十秒。
2. 登录页点「注册」，创建本机账号。登录后会看到「快速开始」。

【在工作区聊天】
点「配置聊天模型」。API 密钥是服务平台发给你的一串字符，若用它调用模型来回复你。
选你已有密钥或订阅的平台。第一次使用，可以先选一个平台，再按提示开通。
· 使用 DeepSeek 官方时，打开 DeepSeek 密钥页面，登录开放平台后创建并复制 API 密钥。
· 使用 OpenCode Go 时，打开 OpenCode Console，登录后从右上角进入
  Account → Personal API keys → Add API key，在已订阅 Go 的工作区创建并复制密钥。
若会预填相应的接口和模型。回到若粘贴密钥，点「测试并启用」，通过后点「开始对话」。
中转或本机服务按窗口提示填接口地址和模型名。

【QQ 自动回复】
打开「QQ Agent → 运行配置」，点「扫码登录 QQ」，用机器人账号在手机上确认。
点「使用工作区模型」，或点「给 QQ 单独配置」。
打开自动回复，把另一个 QQ 号加到白名单，再用那个账号私聊机器人。

【B 站】
在「B站 Agent」顶部点「扫码登录 B 站」，用手机哔哩哔哩扫码确认。
要提交视频、修改稿件或回复评论，在「账号」打开「允许投稿和回复」。
想生成 AI 评论时可以使用工作区的聊天模型。
