> 生效日期：2026-11-16　｜　基准页面：**QQ Agent**　｜　适用范围：全应用（首页、工作区、QQ、B站、鱼窝、记忆、心情、人格、部署、节点、命令、账号、设置）
>
> 本规范由已落地的 QQ Agent 页面反向提炼。**后续所有页面改造、新增页面，一律按本文执行**，不再逐页讨论风格。

## 0. 三条铁律

| #     | 铁律           | 说明                                                                |
| ----- | ------------ | ----------------------------------------------------------------- |
| **1** | **一页最多三个容器** | 一个页签 = 一个页面。页内可见卡片（容器）**不超过 3 个**，最佳 2 个。超了就拆页签，不允许纵向堆叠滚动         |
| **2** | **玻璃三层**     | 大容器（淡色玻璃）→ 内层凹槽（比大容器深一档的半透明层）→ 选中态（着色而非白）。**禁止任何不透明度 > 0.8 的白色块** |
| **3** | **功能不丢**     | 改造只做"重新摆放 + 重新上材质"，不删功能、不改接口、不动 DOM id。改造前后功能清单必须逐条对得上            |

> 判定"容器"：一整个 `.card`（含其内部所有内容）算 1 个容器。  
> Hero 头图、页签栏属于**页面框架**，不计入容器数量。

## 1. 页面骨架（所有页面统一）

```
┌──────────────────────────────────────────────────────────┐
│  顶部栏：搜索（全局） / 主题 / 窗口按钮                      │  ← 全局固定，不在页面内
├──────────────────────────────────────────────────────────┤
│  ① Hero 区（页头）                                        │  高 204–236，圆角 24
│     图标 + 大标题 + 状态点 + 副标题 + 一句描述 + 右侧立绘     │
├──────────────────────────────────────────────────────────┤
│  ② 页签栏（胶囊）                                          │  高 34，间距 6
│     [页签1] [页签2] [页签3] ...（2–5 个，最多 6）            │
├──────────────────────────────────────────────────────────┤
│  ③ 页容器区（当前页签的内容）                                │  容器 ≤ 3，等高
│     [ 容器 A ]  [ 容器 B ]  [ 容器 C ]                      │
└──────────────────────────────────────────────────────────┘
```

### 1.1 Hero 两种规格

| 类型 | 适用 | 规格 |
|---|---|---|
| **标准 Hero** | 产品页（QQ Agent、B站 Agent、鱼窝）——带角色立绘 | 高 204–236，标题 33，右侧立绘 |
| **紧凑 Hero** | 功能页（心情、人格、记忆、部署、节点、命令、账号、设置） | 高 ~76（内边距 `16px 20px`），图标 44，标题 23，说明 12，右侧操作组；无立绘 |

紧凑 Hero 结构：`[图标 44] 标题 + 状态点 / 说明 …………………… [操作按钮组]`

### 1.1.1 标准 Hero 规格

| 项    | 值                                                                                                                       |
| ---- | ----------------------------------------------------------------------------------------------------------------------- |

| 背景   | `linear-gradient(120deg, rgba(124,147,255,.18), rgba(154,130,255,.10) 46%, rgba(255,158,196,.10))`；深色 `.13 / .07 / .06` |
| 图标   | 54×54，圆角 16，浅色 `rgba(255,255,255,.55)` 底 + 1px 描边                                                                       |
| 主标题  | 33px / 700 / `-0.02em`，与状态点同行，间距 10                                                                                     |

### 1.2 页签栏规格

| 状态 | 样式                                                                                                                        |
| -- | ------------------------------------------------------------------------------------------------------------------------- |
| 默认 | 高 34、`border-radius:999px`、内边距 `0 15px`、字号 12、图标 15；浅色 `rgba(124,147,255,.08)` + 描边 `rgba(109,139,255,.18)`，文字 `--ink-2`  |
| 悬停 | 背景提到 `.16`，文字 `--ink`，上浮 1px                                                                                              |
| 选中 | `linear-gradient(135deg, var(--accent), var(--accent-2))` + 白字 + `box-shadow:0 10px 22px -14px rgba(109,139,255,.85)`，无描边 |
| 深色 | 默认 `rgba(255,255,255,.06)` + 描边 `rgba(200,195,255,.16)`                                                                   |

**页签顺序约定**：配置类 → 数据/状态类 → 内容类 → 记录类。  
**命名**：2–5 个汉字，动词或名词短语（"运行配置""白名单管理""最近对话""审计日志"），不加标点。  
**记忆**：页签选择写入 `localStorage`，下次进入回到上次那一页。

### 1.3 页容器区布局模板

| 模板           | 栅格                          | 适用              |
| ------------ | --------------------------- | --------------- |
| **A 单栏**     | `minmax(0,1fr)`             | 表格、日志、对话流       |
| **B 双栏（左重）** | `340px minmax(0,1fr)`       | 配置表单 + 状态/预览    |

| **D 三栏**     | `300px minmax(0,1fr) 300px` | 三块信息并列（仅当确有第三块） |

- 栅格间距：**14px**
- **等高**：`align-items: stretch`，同页容器高度一律拉齐（矮的由内部留白补齐）
- 页容器区距页签栏 **14px**；页面底部留白 18px

## 2. 设计 Token（明 / 暗两套，不得自造颜色）

### 2.1 材质（玻璃三层）

| 层级                              | 浅色                                                                                                                                                                                                                                        | 深色                                                 |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| **大容器**                         | `linear-gradient(120deg, rgba(124,147,255,.13), rgba(154,130,255,.075) 46%, rgba(255,158,196,.085))` + `rgba(255,255,255,.34)`；描边 `rgba(255,255,255,.85)`；阴影 `0 20px 44px -34px rgba(96,86,170,.34), inset 0 1px 0 rgba(255,255,255,.72)` | `rgba(38,32,68,.90)`；描边 `rgba(200,195,255,.10)`    |
| **内层凹槽**（输入、下拉、文本域、ghost 按钮、标签） | `rgba(124,147,255,.10)`；描边 `rgba(109,139,255,.22)`；`inset 0 1px 2px rgba(96,86,170,.06)`                                                                                                                                                  | `rgba(255,255,255,.06)`；描边 `rgba(200,195,255,.16)` |
| **选中态**                         | `rgba(109,139,255,.14)` + `inset 0 0 0 1px rgba(109,139,255,.26)` + 文字 `#5B6FE0`                                                                                                                                                          | `rgba(109,139,255,.28)` + 文字 `#DCE4FF`             |

> **为什么内层不是白色**：浅色模式页面底色接近纯白，白色内层看不出边界；只用白色会变成"实白块"。正确做法是让内层**比大容器深一档**（淡蓝紫薄层），既可见又不发白。

## 3. 组件规范

### 3.1 卡片容器 `.card`

- 圆角 20，内边距 16，材质见 2.1「大容器」
- 同页容器等高
- **禁止卡片内再套卡片**；卡片内只允许「凹槽 / 列表行 / 分区标题」三类内层

### 3.2 卡片头

```
[ 图标芯片 34×34 ] [ 标题 13px/650 ] [ 说明 10.5px --faint ]        [ 标签 / 开关 / 操作 ] 右对齐
```

- 图标芯片：圆角 11，底色 `--pa-soft`（页色 13% 透明），描边 `color-mix(--pa 22%, --line)`，图标 18×18 用页色
- 图标统一 1.6–1.7px 描边线性 SVG，`stroke-linecap:round`
- 头部右侧控件顺序：标签 → 开关 → 次按钮 → 主按钮（最多 2 个控件）

### 3.3 表单控件（内层凹槽）

| 状态 | 规格                                                                                         |
| -- | ------------------------------------------------------------------------------------------ |
| 默认 | 高 30–32，圆角 12，底色/描边见 2.1；字号 11.5；placeholder `--muted`                                     |
| 聚焦 | 底色 `rgba(124,147,255,.17)`、描边 `rgba(109,139,255,.55)`、外圈 `0 0 0 4px rgba(109,139,255,.12)` |
| 禁用 | 透明度 .5，`cursor:default`                                                                    |
| 下拉 | **必须使用自绘玻璃下拉**（原生 select 弹层为系统白底，无法改色）                                                     |

**下拉（玻璃）规格**：触发器同输入框；菜单 `top: +6px`、圆角 14、内边距 5、项高 28、圆角 9、选中项着色、`backdrop-filter: blur(16px)`、阴影 `0 18px 36px -18px rgba(96,86,170,.45)`。原生 `select` 保留在 DOM 中作为数据载体。

### 3.4 按钮层级

| 层级         | 样式                                                                         | 用途           |
| ---------- | -------------------------------------------------------------------------- | ------------ |
| 主按钮        | `linear-gradient(135deg, --accent, --accent-2)`，文字色 **`--accent-ink`**（浅色=白 / 深色=#141033），高 32（sm）/36，圆角 12 或 999 | 每页**最多 1 个** |
| 次按钮（ghost） | 凹槽材质（2.1），文字 `--ink-2`                                                     | 并列动作         |
| 小按钮        | 高 24，字号 11，圆角 8（`btn xs`）                                                  | 行内           |
| 危险         | 文字 `--bad`，悬停底色 `rgba(255,112,137,.12)`                                    | 删除/移除        |

### 3.5 行（键值 / 列表）

**键值行**：左标签 `--muted` 11.5，右值 `--ink-2` 11 `--mono`，上下 7px，底部 1px `--line` 分隔（末行无）。

**列表行**：`[头像 32 圆] [主文字 12/600 + 可选徽章] [次行 10 mono] ……… [行内操作]`，上下 8px。  
头像：圆 32，`linear-gradient(140deg, --accent-soft, --wash-2)`，首字 12/600 用主色。

**表格**：表头 10.5 `--muted`，斑马纹，行高 ~30，末行无下边框。

### 3.6 标签 / 徽章 / 开关

- 标签 `.tag`：高 20、圆角 7、10px `--mono`、凹槽材质
- 徽章 `.wlTag`：9px、圆角 6、`--accent-soft` 底 + 主色文字（如"主人"）
- 开关：轨道 34×18，滑块 14 白圆，开启时轨道用主色渐变

### 3.7 分段控件 / 子页签

外壳：圆角 10、内边距 3、底色 `rgba(124,147,255,.07)` + 描边；项高 26、字号 11、圆角 8；选中项用「选中态」材质 + `--shadow-sm`，不用白底。

### 3.8 对话气泡

| 角色     | 位置    | 样式                                                                              |
| ------ | ----- | ------------------------------------------------------------------------------- |
| 她（机器人） | **左** | `linear-gradient(135deg,#7C93FF,#9A82FF)`，白字，圆角 18 / 左下 6                       |
| 对方（用户） | **右** | 浅色 `rgba(255,255,255,.42)` + 描边；深色 `rgba(52,45,86,.94)`；文字 `--ink`；圆角 18 / 右下 6 |
| 失败     | 左     | `rgba(255,112,137,.12)` 底 + `--bad` 文字                                          |

气泡上方元信息：名称 12/600 + 时间 10.5 `--muted`，与气泡间距 5。

### 3.9 空态

虚线面板（1.5px dashed `--line-2`），圆角 12，最小高 88，居中，文字 `--muted` 11.5，行高 1.8。**必须有引导语**，不能只写"暂无数据"。

### 3.10 二维码块

容器用凹槽材质（圆角 12，内边距 14）；**二维码图片本身保持 `#fff` 底 + 6px 内边距**（保证识别率）。

### 3.11 进度 / 条形

轨道高 4–6，圆角 99，底色 `--line-strong`；填充用页色或语义色渐变；可选端点光 `box-shadow:0 0 10px -2px currentColor`。

## 4. 交互与状态

| 交互   | 规则                                                 |
| ---- | -------------------------------------------------- |
| 卡片悬停 | 只加阴影 `--shadow`，**不上浮不缩放**（数据卡）                    |
| 行悬停  | 底色 `--wash`，圆角 9                                   |
| 按钮悬停 | 提亮 6%，上浮 1px；按下缩至 .97                              |
| 焦点可见 | 统一 4px 主色光环，禁止默认蓝色描边                               |
| 过渡   | 160–220ms，缓动 `--ease-out` / `--spring`             |
| 减少动效 | 尊重 `prefers-reduced-motion`，全部动效归零                 |
| 滚动   | 页面滚动在 `.view`；卡内长列表在卡内滚动（列表卡最大高度 `--vhpx - 380px`） |

## 6. 交付验收清单（每页改造后逐条打勾）

- [ ] 页内可见容器 **≤ 3**
- [ ] 每页有 Hero + 页签栏，页签 2–5 个，命名 2–5 字
- [ ] 同页容器**底部齐平**（等高）
- [ ] 页面内**没有任何不透明度 > 0.8 的白色块**（用截图或计算样式扫描验证）
- [ ] 输入框/下拉均为**凹槽材质**，聚焦不变白
- [ ] 下拉为**自绘玻璃下拉**，无系统白弹层
- [ ] 按钮：每页主按钮 ≤ 1
- [ ] 卡片内**没有嵌套卡片**
- [ ] 浅色 / 深色两套都检查过，文字对比度正常
- [ ] 功能清单逐条对照：改造前有哪些按钮/输入，改造后一个不少
- [ ] 页签选择记忆生效（重进应用回到上次页签）

---

## 7. 禁止事项（反例）

1. ❌ 一页塞 4 张以上卡片然后靠滚动看完 —— 拆页签
2. ❌ 内层用纯白/90% 白块（含 ghost 按钮、标签、聚焦输入框、原生下拉弹层）
3. ❌ 内层和大容器同色导致边界消失 —— 内层必须深一档
4. ❌ 卡片里再套卡片（三层嵌套）
5. ❌ 一页里两个主色渐变按钮抢焦点
6. ❌ 自造颜色 / 自造圆角 / 自造字号（只能取第 2 节的 token）
7. ❌ 同一页面出现两套栅格宽度
8. ❌ 改版时顺手改接口、改 DOM id、删功能
