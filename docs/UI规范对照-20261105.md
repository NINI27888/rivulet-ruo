## 二、组件写法

- **卡片**:`background:var(--glass); border:var(--px) solid var(--line); border-radius:var(--r); box-shadow:var(--shadow), var(--pixel-shadow); backdrop-filter:blur(16px) saturate(1.15)`;`::before` 内嵌 6px 一圈 1px 细线。
- **输入框**:`padding:9px 11px; border-radius:9px; background:var(--chip); border:2px solid var(--line); font-size:13.5px`;focus 时 `border-color:var(--line-strong); box-shadow:0 0 0 3px color-mix(in srgb,var(--leaf) 18%,transparent)`。
- **按钮**:`padding:9px 14px; border-radius:9px; font-weight:600; background:color-mix(in srgb,var(--leaf) 30%,transparent); border:2px solid var(--line-strong)`;hover `background:…45%` + `transform:translate(-1px,-1px)`;active `translate(1px,1px)`;`.ghost` 用 var(--chip)。
- **温室背景层**(fixed, pointer-events:none):`.beams` 斜射光束(112deg 渐变 + mix-blend-mode:screen,浅色用 --sun、深色用 --lamp)、`.frame` 118px 网格线、`.plants` 底部 120px 像素植物条(内联 SVG data-uri,`shape-rendering='crispEdges'`)、`.shelf` 一条横线。

## 六、落地注意

- 桌面端是 Tauri,`ui/style.css` 直接搬上面 token;植物条内联 SVG 可以照抄 data-uri。
- 字体 Zpix 不联网拿不到,**回退链**已经写好(Consolas 等),先用回退,别引外链。
- 改之前先备份:`rivulet-app/ui/index.html`、`style.css`、`app.js`。
- 改完要 `cargo build --release` 重新编(exe 内嵌前端资源),再复制到 `dist/`。
